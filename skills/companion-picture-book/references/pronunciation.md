# 发音教学稿

## 语义与来源

本项目的「罗马音」按用户明确约定指**中文谐音**，例如 Daddy → 戴迪；不是拼音或 DAD-ee 这种拉丁字母拼读。文件与标注使用「中文谐音」名称，说明中可加「用户所说的罗马音」。

每个 `texts` 文字块在原有 `id`、`zh`、`en` 之外提供：

- `en_ipa`：默认美式参考 IPA，整块用 `/.../` 包围；`|` 可标记句间停顿。保持同一本的口音与标注方式一致。
- `en_homophone`：对应同一句英文的中文近似读音，用空格和标点帮助分词与停顿；不能填中文翻译。

先确定英文原句，再编写标注。按语境核对词义、词性、重音与读音；专名先明确拟用读法。不确定的读音查询可靠词典或原声，不编造核实记录。无需强行模拟所有连读，标注为教学参考，不承诺与每台设备的声音逐音一致。

英语中的 /æ/、/ɪ/、/v/ 等不能用汉字准确表达。教学稿附一条简短说明：「中文谐音仅作近似记忆提示，不是标准发音；请先听英文原声再跟读。」音标稿说明默认口音及停顿符号。提示是给家长看的，不作为正文朗读，也不自动加入孩子看的绘本图片或打印版。

## 五份交付

1. `双语对照稿.txt`：每页、每块按中文 → 英文 → 音标 → 中文谐音排列。
2. `中文朗读稿.txt`：中文原文，页间空行。
3. `英文朗读稿.txt`：英文原文，页间空行，可直接用于朗读或语音合成。
4. `英文朗读稿-音标版.txt`：页号与文字块 ID、英文原句、对应音标。
5. `英文朗读稿-中文谐音版.txt`：页号与文字块 ID、英文原句、对应中文谐音。

示例块：

```text
【第 01 页】
[body]
中文：爸爸，我想你啦。
English: Daddy, I miss you.
音标：/ˈdædi, aɪ mɪs juː/
中文谐音：戴迪，爱 米斯 优。
```

封面及对象标签同样覆盖。无字页在对照稿和教学稿中标记「无朗读正文」，两份纯正文稿跳过；不得为凑标注自行添加台词。

导出器负责检查字段完整性并保持顺序，不会生成或校正音标。使用同一个文稿导出五份，逐块检查标注与原句是否匹配；改英文后同步重写该块两个标注，再导出新 revision。缺标注时将教学稿标为未完成，不填占位音标或复用其他句子。

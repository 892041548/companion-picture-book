# 制作、状态与交付

## 保存当前作品

在用户工作区创建 `storybook/<作品短名>/`。不在技能源码目录写入儿童照片或作品。推荐文件按实际需要建立：

```text
project-state.json
assessment.md
character-style.md
page-plan.md
manuscript.json
prompts/page-01.md
images/page-01-v1.png
final/page-01-v1.png
texts/双语对照稿.txt
texts/中文朗读稿.txt
texts/英文朗读稿.txt
texts/英文朗读稿-音标版.txt
texts/英文朗读稿-中文谐音版.txt
parent-guide.md
qa-report.md
delivery.md
```

单页可简化记录，但仍保留文字来源、角色／风格、最终文件与检查结果。已有文件不覆盖，修订用新版本；不要把原始儿童照片打入公开技能包或最终分享包。

## 项目状态

`project-state.json` 保存本次实际值，缺失值使用 `null`，不把示例当作用户选择。至少包含：

| 字段 | 内容 |
| --- | --- |
| `stage` | `intake`、`assessment`、`await_mode`、`await_content_style`、`production`、`qa`、`complete` 或 `partial` |
| `age_input` / `observations` | 用户年龄原文和共读反馈 |
| `mode` | `single` 或 `story` |
| `content_revision` / `style_id` | 当前内容版本和已选画风 |
| `photo_mode` / `references` | `none`、`face`、`full_appearance` 或 `family`；角色与可实际访问的参考图对应关系 |
| `confirmations` | 分支、内容版本、风格的确认；每项保存用户答复摘要或明确委托 AI 决定的范围 |
| `generation` | 图片工具可用性、已生成页、版本和路径；工具未生成不得填已完成 |
| `qa` | 每页状态、未解决项、修复轮数 |

从 `await_content_style` 进入 `production` 前检查内容与风格是否已确认。用户说「可以」只确认上轮清楚展示的内容，不自动确认尚未给出的风格。用户一次给全条件或明确委托直接制作时，可以合并阶段。

选故事后收到大类，下一步是写梗概；选单页后收到主题，下一步是单页方案与风格。照片缺失只阻断需要参考照片的角色生成，其他文案工作可以继续；用户可选择无照片角色。

## 角色与连续性记录

`character-style.md` 对每个角色分别写：

- 固定 ID、名字／称呼、人物关系、参考图来源与用途。
- 年龄感、体型比例、脸型与下颌、眼睛形状与相对位置、眉形、鼻口特征、可见肤色、发际线和发型；只记录实际可见或用户明确设定的特征，不推断族裔等身份。
- 固定服装、配饰及左右位置；哪些随剧情允许变化。
- 肢体与遮挡规则，按角色实际设定检查。残障、义肢或有意设计的身体特征应保持一致，不当作“异常”纠正。
- 所选风格 ID、颜色、画材、文字版式、已检查的角色基准图。

对照片角色先创建插画基准或关键页。照片用来核对授权保留的外形；以后各页同时对照基准和角色档案。实际参考图在每次生成请求中显式传入（以工具支持为准），不要假定模型自动记住多轮前的人脸。不可用时说明相似度控制的限制，不声称成功引用。

场景记录 2–5 个真正有用的固定锚点，例如门与窗的相对位置、地毯形状、床边灯。记录世界空间关系，不把同一物品在镜头中的屏幕位置死锁：换机位可以变位置，但门不能无故换墙。

关键道具使用状态表：`页码 → 持有人／位置 → 数量 → 当前状态 → 本页变化`。换场景时只携带已交代的随身物品；返回原场景时恢复最后状态，而不是初始状态。

## 分镜与文本

故事页计划字段：页号、上一页留下的状态、本页触发、一个核心动作或情绪变化、画面证据、下一页衔接、道具状态、文字区。第一张建立情境，最后一张收束；不要求结尾再留悬念。

单页计划字段：主题、一个互动目标、主体与干扰项、孩子可见文字、指认／匹配条件、成人提示、文字区。开放情绪讨论允许多个答案；数数与配对要有清楚且准确的对象和答案。单页合集逐张自洽，不强制故事起承转合。

把最终画面中的**所有需要朗读的文字**放在 `manuscript.json`。标题、正文、对象标签、拟声词分别作为文字块，按页面阅读顺序排列。亲子提示不放入文字块。页码等非朗读导航可另行排版，但不能混入朗读稿。

标准中英双语格式：

```json
{
  "schema_version": 2,
  "revision": "r1",
  "mode": "story",
  "language_mode": "zh-en",
  "pages": [
    {
      "id": "01",
      "kind": "content",
      "texts": [
        {"id": "body", "zh": "我听见脚步声。", "en": "I hear footsteps.", "en_ipa": "/aɪ hɪr ˈfʊtsteps/", "en_homophone": "爱 希尔 富特斯泰普斯。"}
      ],
      "parent_tip": "一起轻轻模仿走路的声音。"
    },
    {
      "id": "02",
      "kind": "content",
      "texts": [
        {"id": "body", "zh": "爸爸回来了！", "en": "Daddy is home!", "en_ipa": "/ˈdædi ɪz hoʊm/", "en_homophone": "戴迪 伊兹 后姆！"}
      ],
      "parent_tip": "指一指爸爸在哪里。"
    }
  ]
}
```

规则：

- 内页从 `01` 连续编号，JSON 数组顺序就是最终顺序。可选封面放最前，`id` 为 `00`、`kind` 为 `cover`，其标题也在 `texts` 中。
- `mode=single` 只包含一张内容页；一组单页卡使用 `mode=cards`，这是单页分支的导出形式。故事使用 `story`。单页和卡片不用封面。
- 每页文字块 ID 唯一；两种语言都必须有非空文本。完全无字页用 `texts: []`，对照稿会标记，朗读稿不为该页添加语言说明。
- 字符串不在首尾填空白，换行只用于有意的段内断行。句末标点也属于主文稿，导出不自动纠正或翻译。
- 默认 `zh-en`；用户要求单语或其他语言时按其要求调整文稿和交付，当前脚本只支持中英双语，不能把它的输出冒充其他语言版本。
- 修文案后增加 `revision`，重新导出所有受影响带字图片和 TXT；仅增加家长发音辅助且正文未改时，保留原图片。在 QA 中记录用于渲染的文稿版本。

## 生成与排字

每页提示词包括：页号与比例、该角色的固定外形、参考图各自用途、当前场景、一个核心动作、情绪、机位与遮挡、道具状态、所选风格、文字留白、图文对应的必要证据。

文字涉及声音、回忆、猜测或比喻时不要求凭空画出对象。例如「好像是爸爸」可以画孩子朝门倾听，不提前把尚未登场的爸爸画进室内。必须让事件状态与文字一致，不能把「听见」检查成「必须看见声源」。

多页先用关键页检验角色和画风，再逐页生成。封面仅在方案包含时生成；不用强行给单页加封面。返回图片后实际查看，记录通过与问题，不批量跳过图像检查。

优先生成无字底图，再用确定的排版工具读取 `manuscript.json` 合成中英文字到最终图片。采用明确授权的合成方式与可用工具；若图像编辑工具有专门限制，遵守其要求。HTML/CSS 可以作为排版实现，但只有真正渲染并导出的 PNG 才能称为带字成品图。PDF 仅在用户需要且实际导出时交付。

用户明确要求文字随图生成，或每页仅有少量短句且当前图像工具能清楚渲染时，可尝试直接生成带字页面。把主文稿的确切双语文案写入提示词，逐页逐字目视检查；只有字形、内容、阅读顺序与版式均通过才将其作为成品。长正文或直接生字不稳定时优先使用可控排版。直接生字出错可局部修复；若两轮仍不稳定，说明问题，采用可用的排版方式修正。没有可用的排字／导出能力且带字图未通过时，交付无字底图和文本，标记带字成品未完成，不假装已融合双语。

版式需满足：两种语言阅读顺序固定、中文英文清晰可辨、文本背景对比足够、文字不遮脸和关键动作、页间字体字号一致、安全边距足够。不要将插画硬拼成多格再冒充独立页面。

## 导出五份 TXT

从技能目录运行，参数路径换成当前作品的实际路径：

```sh
python3 scripts/export_texts.py /absolute/path/to/manuscript.json --out /absolute/path/to/texts/r1
```

脚本仅依赖 Python 标准库，默认拒绝覆盖已有生成文件；文稿修订后使用新的输出目录。明确要更新同一目录时可加 `--overwrite`，其作用仅限这五份生成的 TXT。

- 双语对照稿：页号、文字块编号、中文、英文原句、音标、中文谐音；有封面时放最前。
- 中文朗读稿：只含中文文字块；页与页之间留空行。
- 英文朗读稿：只含英文文字块；与中文保持同样的有字页顺序。
- 英文朗读稿-音标版：逐页逐块保留英文原句，下方附美式参考 IPA。
- 英文朗读稿-中文谐音版：逐页逐块保留英文原句，下方附中文谐音（本项目中用户所说的「罗马音」）。

新作品使用 schema 2，每个文字块还必须有 `en_ipa` 和 `en_homophone`；包括封面标题、标签、拟声词。字段内容的编写与检查见 [发音教学稿](pronunciation.md)。schema 1 仅用于读取旧作品并导出原来的三份稿，不代表新版五份交付完成；续作需要新增教学稿时，补齐字段后升到 schema 2 和新 revision。不能运行 Python 时，按同样的五份格式手工导出，不省略发音辅助。

无字页没有朗读内容，不添加“无字页”等提示到朗读稿。脚本成功只证明结构与导出一致；仍需读文本、看图片，检查含义和最终字形。

## 交付规则

`delivery.md` 列明页号、当前已检查的最终文件和版本。附五个 TXT 的真实路径、独立家长共读提示、质量报告简述。文字或图片有缺失时使用 `partial` 并列出缺失，不把提示词、预览图或参考图计入完成页数。
